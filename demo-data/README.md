# Демонстрационная база знаний

`knowledge-base.zip` — предоставленная организаторами учебная база кейса ПСБ:
21 TXT-документ с законами и вымышленными документами компании.
Это не реальные внутренние документы банка.

Архив включён для воспроизводимого запуска прототипа из репозитория.
В ZIP для автоматической оценки он не попадает: на платформе данные
передаются отдельно через `DATA_DIR`.

Для другого набора документов задайте `DATA_DIR` в `.env`.
Оба сервиса должны получать один и тот же архив. Смену набора документов
выполняйте в новом состоянии бэкенда, чтобы не смешивать документы разных баз.
